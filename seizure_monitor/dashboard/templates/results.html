How to read these numbers

  • A first indication, not clinical validation. {{ s.seizures }} seizures is a small test set; that is why the confidence interval is wide.
  • Alert time is counted from the clinical onset in the dataset labels. In focal-to-bilateral seizures that is the focal start; the convulsive phase, which this system targets, begins later and is not labelled.
  • Settings were chosen before part of the data existed. Thresholds were set on the first two patients; the seizures of the later patients were then all detected with the same settings.
  • Repeat alerts within one seizure ({{ s.repeat_detections }}) are not counted as false alarms: the live system merges them into a single alert.
  • The seizure-free footage is mostly calm. False alarms from vigorous normal activity in bed (turning over, getting up, someone making the bed) still need to be measured on more data.
  • Detectors: {{ r.detectors }}. Matching tolerance ±{{ r.tolerance_s | round | int }} s.
